# Documentación técnica detallada

Esta carpeta es para documentación técnica en profundidad (diagramas,
esquemas de base de datos, flujos de autenticación, etc.) a medida que el
sistema crezca. La visión general vive en [`/ARCHITECTURE.md`](../../ARCHITECTURE.md).

Contenido actual:

- [`database-schema.md`](database-schema.md): esquema de base de datos de
  la Fase 0/1 y convenciones para extenderlo.
- [`authentication.md`](authentication.md): flujo de autenticación y
  autorización actual.

A añadir cuando exista (no crear vacío por adelantado): diagramas de
despliegue en producción, diagramas de flujo de datos si se incorporan
integraciones externas, esquema de eventos si se incorpora mensajería.
