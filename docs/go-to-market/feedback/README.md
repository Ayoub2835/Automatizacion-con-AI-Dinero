# Fichas de feedback

Una ficha por conversación real con una gestoría (reunión, demo,
onboarding o seguimiento). Nómbralas
`AAAA-MM-DD-nombre-gestoria.md`. La plantilla a copiar está en
[`../proceso-feedback.md`](../proceso-feedback.md).

Todavía no hay ninguna ficha — esta carpeta se llena a partir de la
primera reunión real.
